# بسته روابط عمومی ایران (iran-pr)

پنج اسکیل تخصصی روابط عمومی که منطق حرفه‌ای جهانی را بر بستر واقعیت اکوسیستم
ایران — تقویم و مناسبت‌ها، نقشه رسانه‌ای، مسیرهای تأیید، تشریفات و خطوط قرمز —
اجرا می‌کنند.

## اسکیل‌ها

| اسکیل | کِی فعال می‌شود | حجم مرجع |
|---|---|---|
| `press-conference-planner` | نشست خبری، کنفرانس مطبوعاتی، دعوت از رسانه‌ها، رونمایی خبری | ۵ مرجع + ۲ قالب |
| `iran-exhibition-pr` | نمایشگاه، غرفه، غرفه‌سازی، جانمایی، پیش‌ثبت‌نام، بودجه نمایشگاه | ۶ مرجع + ۱ قالب |
| `event-planner` | افتتاحیه، همایش، سمینار، وبینار، جشن سازمانی، رویداد برندی و اجتماعی | ۴ مرجع + ۲ قالب |
| `sponsorship-planner` | حمایت مالی و اسپانسرشیپ از رویداد دیگران، فعال‌سازی، بازگشت سرمایه | ۳ مرجع + ۲ قالب |
| `media-visit-planner` | بازدید رسانه‌ای، تور خبرنگاران از کارخانه، پروژه یا سایت عملیاتی | ۳ مرجع + ۲ قالب |

هر اسکیل یک `SKILL.md` سبک دارد که همیشه بارگذاری می‌شود، و محتوای تفصیلی در
`references/` که فقط هنگام نیاز خوانده می‌شود. قالب‌های آماده (چک‌لیست، سناریو،
متن دعوت‌نامه، کاربرگ امتیازدهی، فرم رضایت) در `assets/` هر اسکیل هستند.

## قالب‌های آماده

| قالب | در کدام اسکیل |
|---|---|
| چک‌لیست اجرایی با شمارش معکوس | هر پنج اسکیل |
| متن دعوت‌نامه، یادآوری، embargo، اصلاح خطای انتساب | `press-conference-planner` |
| سناریوی اجرا (حضوری، ترکیبی، چندروزه) | `event-planner` |
| کاربرگ امتیازدهی شش‌معیاره فرصت حمایت | `sponsorship-planner` |
| فرم رضایت تصویربرداری (استاندارد و محیط حساس) | `media-visit-planner` |
| قالب چک‌لیست هفت‌فازی نمایشگاه | `iran-exhibition-pr` |

## دو فایل مرجع مشترک

هر اسکیل در پوشه `shared/` خودش یک نسخه از این دو فایل دارد:

- **`iran-context.md`** — تقویم و زمان‌بندی، مسیرهای هماهنگی، نقشه رسانه‌ای،
  تشریفات، خطوط قرمز مشترک، لجستیک، توافق‌های حرفه‌ای با خبرنگار
- **`sector-profiles.md`** — شش پروفایل سازمانی (دولتی، مدیریت شهری، شرکت بزرگ،
  استارتاپ، سازمان مردم‌نهاد، دانشگاه) و قاعده رویدادهای مشترک

**چرا تکرار شده‌اند:** هنگام نصب، پوشه پلاگین کپی می‌شود و ارجاع به فایل‌های بیرون
پوشه اسکیل کار نمی‌کند. تکرار، تنها راهی است که هر اسکیل مستقل کار کند.

**نکته نگهداری:** اگر محتوایشان را به‌روز کردید، تغییر را در هر پنج پوشه اعمال
کنید.

## اسکیل‌های مکمل

برای تولید فایل خروجی، این اسکیل‌ها جداگانه در Cowork موجودند و در متن اسکیل‌ها
به آن‌ها ارجاع داده شده است:

- `docx` — سند برنامه، طرح جامع، گزارش ارزیابی
- `xlsx` — چک‌لیست اجرایی، بودجه، جدول لیدها
- `pptx` — ارائه به مدیریت
