# قالب چک‌لیست اجرایی رویداد

با **تاریخ شمسی واقعی** پر کن. ستون «مهلت» باید تاریخ باشد، نه «یک ماه قبل».
اگر خروجی xlsx می‌سازی، هر فاز یک شیت جداگانه و ستون وضعیت با اعتبارسنجی داده
(انجام‌شده / در جریان / معوق).

**مقیاس‌گذاری:** رویداد بزرگ یا همایش چندسخنرانه از T-90 · رویداد متوسط از T-30 ·
رویداد کوچک از T-14. ردیف‌های ◆ در هیچ مقیاسی حذف نمی‌شوند.
