# قالب چک‌لیست اجرایی بازدید رسانه‌ای

با **تاریخ شمسی واقعی** پر کن. شمارش معکوس از **T-21 برای بازدید یک‌روزه
درون‌شهری** و **T-45 برای بازدید چندروزه یا نیازمند سفر**.

**ردیف‌های ◆ حذف نمی‌شوند.** ردیف‌های مجوز، هماهنگی حراست و تأیید تعداد نهایی را
زودتر از آنچه لازم به نظر می‌رسد بگذار — این‌ها تعیین‌کننده کل تقویم‌اند و قابل
فشرده‌سازی نیستند.
