# قالب چک‌لیست اجرایی حمایت مالی

با **تاریخ شمسی واقعی** پر کن. شمارش معکوس از T-60 برای رویداد بزرگ، T-30 برای
رویداد متوسط.

**ردیف‌های ◆ در هیچ مقیاسی حذف نمی‌شوند.** سه ردیفی که همیشه دیر می‌شوند و باید
زودتر از آنچه لازم به نظر می‌رسد شروع شوند: **تولید اقلام بصری**، **تأیید محتوا
توسط برگزارکننده**، و **آماده‌سازی سخنرانی**.
